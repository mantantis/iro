# Security Policy

## Reporting a vulnerability

If you find a security issue in iro — such as terminal escape sequence
injection, escaping the `init.lua` config sandbox, leaking permissions on swap
or history files, or unsafe handling of untrusted files — please do **not** open
a public issue.

Instead, report it privately:

- **Email:** <mailto:mausmann.dev@proton.me>
- **GitHub:** [report a vulnerability](https://github.com/mantantis/iro/security/advisories/new)
  (Private vulnerability reporting).

Please include the iro version (`iro --version`), steps to reproduce, and what
happened. iro is a hobby project maintained by one person, so responses are best
effort, usually within a few days.
